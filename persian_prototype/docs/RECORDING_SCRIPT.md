# Recording script — فهرست ضبط صدا

_Generated from `lib/data/voice_script.dart`. Do not edit by hand._

How to deliver recordings:

- One file per line below, named exactly as the **File** column, saved in `assets/audio/` (`.mp3`, `.m4a` or `.wav`).
- Native Persian speaker, standard (Tehran) pronunciation, warm and unhurried, as if speaking to a 5-year-old.
- Quiet room, no music, about 0.3 s of silence before and after.
- The app plays a recording automatically as soon as the file exists; until then it uses the device's Persian text-to-speech voice, if any.
